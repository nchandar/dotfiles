# tmux Keybindings

Source: `TMUX.md` and `config/tmux/tmux.conf`

## Prefix
- `Ctrl-g` (primary)
- `Ctrl-]` (alternate)

## Daily keys
- `=` or `]`: split horizontally
- `-` or `\`: split vertically
- `h/j/k/l`: resize pane by 5 cells
- `m`: zoom/unzoom pane
- `r`: reload tmux config
- Copy mode (`vi`): `v` start selection, `y` yank

## Extra
- `Meta-c`: attach session in current pane path
