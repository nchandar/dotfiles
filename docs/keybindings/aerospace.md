# AeroSpace Keybindings

Config source: `config/aerospace/aerospace.toml`

## Most-used keys
- `alt-h/j/k/l`: focus left/down/up/right
- `alt-shift-h/j/k/l`: move window left/down/up/right
- `alt-/`: cycle tile layout orientation
- `alt-,`: cycle accordion layout orientation
- `alt--` and `alt-=`: resize down/up
- `alt-tab`: previous workspace
- `alt-shift-tab`: move workspace to next monitor

## Workspaces
- `alt-1..9`: switch workspace
- `alt-shift-1..9`: move focused window to workspace
- `alt-a..z`: switch alpha workspace bindings present in config
- `alt-shift-a..z`: move focused window to alpha workspace

## Service mode
- `alt-shift-;`: enter service mode
- In service mode:
  - `esc`: reload config and return to main mode
  - `r`: flatten workspace tree
  - `f`: toggle floating/tiling
  - `backspace`: close all windows except current
  - `alt-shift-h/j/k/l`: join containers

## Gaps
- Inner: `5`
- Outer: `5`
