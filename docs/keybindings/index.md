# Keybindings Overview

macOS key names used in docs:
- `alt` = `Option (⌥)`
- `cmd` = `Command (⌘)`
- `ctrl` = `Control (^)`
- `shift` = `Shift (⇧)`

## Note on overlap
Hammerspoon and AeroSpace are both enabled. If a shortcut overlaps, the app that captures it first will execute it.
