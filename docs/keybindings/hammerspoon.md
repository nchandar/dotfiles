# Hammerspoon Keybindings

Config source: `config/hammerspoon/init.lua`

## Main modifiers
- `ctrl + option + cmd` for core window actions
- `cmd + option` for wide-screen thirds layout

## Core actions
- `ctrl + option + cmd + Left`: left half
- `ctrl + option + cmd + Right`: right half
- `ctrl + option + cmd + Up`: top half
- `ctrl + option + cmd + Down`: bottom half
- `ctrl + option + cmd + m`: maximize

## Other bound actions
- `ctrl + option + cmd + l`: start screensaver
- `ctrl + option + cmd + z`: open webview demo
- `ctrl + option + cmd + c`: toggle autoclick

## Wide-screen thirds
- `cmd + option + Left`: left third
- `cmd + option + Down`: center third
- `cmd + option + Right`: right third
