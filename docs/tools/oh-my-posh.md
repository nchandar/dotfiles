# Oh My Posh

- Config path: `config/oh-my-posh.omp.toml`
- Symlink target: `~/.config/oh-my-posh.omp.toml`
- Shell init: `~/.zshrc` runs `oh-my-posh init zsh --config ~/.config/oh-my-posh.omp.toml`
- Theme: repo-managed Catppuccin Mocha prompt with rounded pill segments
- Layout: single-line prompt with `path` and the prompt symbol on the left plus git/status/job/runtime/time/battery on the right
- Prompt: the prompt pill flips from green to red on command failure

This setup is also used on Linux/Omarchy with the same config file.
