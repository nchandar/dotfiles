# Neovim

- Config path: `config/nvim/`
- Full details: `config/nvim/README.md`
- Git diff plugin: `diffview.nvim` (configured in `config/nvim/lua/plugins/diffview.lua`)

## Update tooling
`make update` runs:
- `Lazy sync`
- `MasonUpdate`
- `TSUpdate`

## Diffview quick commands
- `:DiffviewOpen`
- `:DiffviewOpen HEAD~1`
- `:DiffviewFileHistory %`
- `:DiffviewClose`
